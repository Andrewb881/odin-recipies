# Odin Recipes

A simple recipe website built with basic HTML as part of [The Odin Project](https://www.theodinproject.com/) Foundations course.

This project helped me practice working with:

- HTML boilerplate structure
- Headings, paragraphs, lists, and images
- Internal and external linking between pages

## Project Features

- Homepage with links to individual recipe pages
- Multiple recipes with ingredients and instructions
- Clean, beginner-friendly HTML layout

## Technologies Used

- HTML
